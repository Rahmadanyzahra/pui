4) USE CASE SUMMARY

Primary actors:
- Parent
- Child (indirect / tracked user)
- System / Backend

Core use cases:
- Parent signs up or logs in to the app
- Parent adds a child profile and maintains child data
- Parent logs child activities (feeding, sleep, play, learning)
- Parent creates and updates schedules with push reminders
- System stores activities, schedules, and analytics
- System performs AI analysis and updates gamification metrics
- Parent views dashboard insights and child status
- Parent sends or uses invite codes for child/family onboarding
- System handles push notification subscriptions and connection tokens
- System records location and screen time data for children

Secondary use cases:
- Parent reviews reports and analytics history
- Parent manages family settings and preferred dashboard
- System maintains session tokens and secure authentication
